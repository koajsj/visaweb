# VisaWeb（中国大陆护照签证信息站）

VisaWeb 是一个面向 **中国大陆普通护照持有人** 的静态签证信息网站。站点定位是信息查询与行前准备，内容以政策、材料和风险说明为主。

核心内容包括：
- 常见目的地签证/免签规则
- 材料清单、办理时长、费用与面试要求
- 高频拒签、补料和入境风险提示
- 材料准备评估、国家对比、时间倒推与 FAQ

## 当前体验

- 首页展示热门目的地卡片，可直接进入对应国家详情。
- 政策库支持国家搜索、地区筛选、重置和结果数量提示。
- 国家详情页展示签证规则、停留规则、材料清单、入境提示、官方链接和社区高频问题。
- 手机端有底部快捷导航，便于快速跳转政策、评估、对比、问答、搜索、列表和详情区域。
- 移动端布局已针对窄屏优化：单列卡片、较大触控区域、可横向滚动的对比表、详情区自动滚动定位。
- 页面动效保持轻量：卡片进入、按钮按压、滚动 reveal，并支持 `prefers-reduced-motion`。

## 主要功能

1. 热门国家签证卡片
- 首页展示 6 个热门目的地
- 显示签证/免签状态、适用人群、规则和停留信息
- 点击卡片进入 `policy/index.html?country=<国家名>`

2. 国家详情页（政策库）
- 仅针对中国大陆普通护照
- 支持搜索国家、签证类型、入境规则关键词
- 支持按地区筛选：亚洲、欧洲、美洲、大洋洲
- 展示签证规则、停留时间、办理时长、费用、有效性、面试要求
- 展示核心材料、补充材料、入境提示、风险提示和官方参考链接

3. 材料准备评估
- 支持输入：出行目的、停留天数、收入、出境记录、拒签史、资金覆盖、行程真实性、翻译/公证准备、材料完整度等
- 输出：通过率、风险等级、分项评分和准备建议
- 对免签国家自动切换为“入境合规提示”模式

4. 国家对比
- 支持同时对比最多 3 个国家
- 对比签证规则、停留、办理时长、面试要求
- 手机端表格可横向滚动，避免内容挤压

5. 办理时间倒推器
- 输入国家和出发日期
- 自动计算建议提交日期
- 对免签国家提示出发前核查项目

6. 常见问题
- 按国家输出 FAQ
- 覆盖材料准备、资金证明、补料风险、免签入境注意事项等

## 项目结构

```text
visaweb/
├─ index.html                  # 首页
├─ styles.css                  # 全局样式、响应式布局、动效
├─ app.js                      # reveal 动效与材料准备评估逻辑
├─ policy/
│  └─ index.html               # 国家详情页
├─ data/
│  ├─ visa-data.js             # 国家签证数据（核心）
│  └─ site-data-bindings.js    # 页面渲染、筛选、对比、倒推、FAQ 绑定
├─ assets/
│  └─ flags/                   # 本地国旗 SVG（避免外链裂图）
├─ admin/
│  └─ index.html               # 轻量数据维护页（localStorage 覆盖）
└─ favicon.svg                 # 站点图标
```

## 本地运行

直接双击 `index.html` 可以打开。

更稳定的预览方式：
- 使用 VS Code Live Server
- 或任意静态服务器，例如 `python -m http.server`

## 数据维护

主要数据在：
- `data/visa-data.js`

每个国家可维护字段包括：
- 国家名、地区、国旗代码
- 是否需签证、签证类型、停留时长
- 办理时长、费用、有效性、面试要求
- 建议递交时间、官方申请路径
- 核心材料、补充材料
- 风险提示、社区高频问题
- 官方参考链接

如新增国家：
- 在 `data/visa-data.js` 增加国家记录
- 在 `assets/flags/` 补充对应 `flagCode.svg`
- 检查首页、政策页、对比、倒推和 FAQ 是否正常渲染

## 质量检查

推荐提交前运行：

```bash
node --check app.js
node --check data/site-data-bindings.js
node --check data/visa-data.js
git diff --check
```

还应检查：
- 页面没有乱码或无关服务入口
- 手机端 360px 宽度下文本不溢出
- 政策页点选国家后详情能正常显示
- 对比表在手机端可以横向滚动

## 使用与合规提示

- 本站内容用于信息参考与行前准备。
- 各国政策可能动态变化，递交前请以官方渠道最新公告为准。
- 社区问题与经验为总结信息，不等同于官方规则。
- 免签不等于无条件入境，边检仍可能要求说明行程、住宿、资金和离境安排。
