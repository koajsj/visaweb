# VisaWeb

VisaWeb 是一个面向中国大陆普通护照持有人使用的签证信息站点。目标不是堆概念，而是把签证准备拆成能执行的清单、时间线和核对项。

## 站点内容

- 首页：热门国家卡片、快速入口、使用说明
- 政策库：按国家查询签证规则、停留要求、办理时长、费用、材料和官方链接
- 材料评估：根据身份、资金、出境记录、表格一致性和材料完整度输出准备度
- 时间倒推：按出发日期生成准备、递交、补件和出发前终检时间线
- FAQ：按国家生成更具体的问答，避免只有空泛提示

## 本地运行

直接双击 `index.html` 即可打开。

更稳妥的方式：

- 使用 VS Code Live Server
- 或任意静态服务器，例如 `python -m http.server`

## 数据维护

主要数据在 `data/visa-data.js`。

每个国家记录包含：

- 国家名、地区、国旗代码
- 是否需签证、签证类型、停留规则
- 办理时长、费用、有效期、面试要求
- 建议递交时间、官方申请路径
- 核心材料、补充材料
- 风险提示、社区高频问题
- 官方参考链接

新增国家时：

- 在 `data/visa-data.js` 增加国家记录
- 在 `assets/flags/` 补充对应 `flagCode.svg`
- 检查首页、政策页、材料评估、倒推器和 FAQ 是否正常渲染

## 质量检查

建议提交前运行：

```bash
node --check app.js
node --check data/visa-data.js
git diff --check
```

还应该检查：

- 页面没有乱码或无关入口
- 手机端 360px 宽度下文本不溢出
- 政策页点选国家后详情能正常显示
- 办理时间倒推器能生成国家差异化时间线
- 材料准备评估能按不同国家输出差异化结果

## 使用与合规提示

- 本站内容用于信息参考与行前准备
- 各国政策可能动态变化，递交前请以官方渠道最新公告为准
- 社区问题与经验为总结信息，不等同于官方规则
- 免签不等于无条件入境，边检仍可能要求说明行程、住宿、资金和离境安排
