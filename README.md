# VisaWeb（中国大陆护照签证信息站）

VisaWeb 是一个面向 **中国大陆普通护照持有人** 的签证信息网站，聚焦“能直接用”的内容：
- 各国签证/免签规则
- 常见材料与办理细节
- 高频问题与风险提示
- 材料准备评估与国家对比

## 主要功能

1. 热门国家签证卡片
- 首页展示热门国家
- 点击卡片可直接进入该国家详情页

2. 国家详情页（政策库）
- 仅针对中国大陆普通护照
- 展示签证规则、停留时间、办理时长、费用、有效性、面试要求
- 展示核心材料、补充材料、入境提示
- 展示社区高频问题与细节坑点
- 提供“前往签证官网”按钮

3. 材料准备评估
- 支持输入：出行目的、停留天数、收入、出境记录、拒签史、资金覆盖、材料完整度等
- 输出：通过率、风险等级、分项评分、优化建议
- 对免签国家自动切换为“入境合规提示”模式

4. 国家对比
- 支持同时对比多个国家
- 可快速查看签证规则、停留、办理时长、面试要求

5. 办理时间倒推器
- 输入国家+出发日期
- 自动计算建议递交时间

6. 常见问题
- 按国家输出场景化 FAQ
- 包括材料准备、流程细节、入境注意点等

## 项目结构

```text
visaweb/
├─ index.html                  # 首页
├─ styles.css                  # 全局样式
├─ app.js                      # 页面基础脚本（含评估逻辑）
├─ policy/
│  └─ index.html               # 国家详情页
├─ data/
│  ├─ visa-data.js             # 国家签证数据（核心）
│  └─ site-data-bindings.js    # 页面渲染与交互绑定
├─ assets/
│  └─ flags/                   # 本地国旗 SVG（防止外链裂图）
├─ admin/
│  └─ index.html               # 轻量数据维护页（本地覆盖）
└─ favicon.svg
```

## 本地运行

直接双击 `index.html` 即可打开。

如需更稳定的本地预览（推荐）：
- 使用 VS Code 的 Live Server
- 或任意静态服务器（Nginx / Python http.server）

## 数据维护说明

主要数据在：
- `data/visa-data.js`

每个国家可维护字段包括：
- 国家名、地区、国旗代码
- 是否需签证、签证类型、停留时长
- 办理时长、费用、有效性、面试要求
- 递交建议时间、申请路径
- 核心材料、补充材料
- 风险提示、社区高频问题
- 官方参考链接

### 国旗说明

项目使用本地 SVG 国旗：
- 路径：`assets/flags/*.svg`
- 如新增国家，请同时补充对应 `flagCode` 和 SVG 文件

## 使用与合规提示

- 本站内容用于信息参考与行前准备。
- 各国政策可能动态变化，请在递交前以对应官方渠道最新公告为准。
- 社区问题与经验为总结信息，不等同于官方规则。
