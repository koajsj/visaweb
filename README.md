# VisaWeb

VisaWeb 是一个面向中国大陆普通护照持有人的签证信息站点。它的目标不是堆概念，而是把签证准备拆成可执行的清单、时间线和核对项。

## 当前功能

- 首页
  - 热门国家卡片
  - 三步式准备流程入口
  - 材料准备评估
  - 办理时间倒推器
  - 常见问题
  - 移动端底部快捷导航
- 政策库
  - 按国家查看签证规则、停留要求、办理时长、费用、材料和官方链接
  - 支持国家搜索、地区筛选和需签/免签状态筛选
  - 支持 `policy/index.html?country=国家名` 直达详情，并可通过 `q`、`region`、`status` 保留筛选状态
- 数据维护页
  - 可在浏览器本地保存一份 `VISA_DATA` 覆盖数据
  - 保存前会校验必填字段、重复国家、官方链接和可信度字段
  - 适合临时调试或本地维护，不会直接改动仓库文件

## 当前收录

站点当前收录 11 个目的地：

- 亚洲：日本、韩国、新加坡、泰国
- 欧洲：法国（申根）、德国（申根）、英国
- 美洲：美国、加拿大
- 大洋洲：澳大利亚、新西兰

## 最近优化

- 首页入口从单纯快捷按钮改成“核对政策、评估材料、倒推时间”的准备流程
- 政策库增加需签/免签筛选，并把搜索范围扩展到材料、风险和官方递交路径
- 政策库筛选条件会写入 URL，复制链接时能保留国家、关键词、地区和状态
- 国家详情补充递交路径、第一优先级和最易出错项，减少只看摘要造成的遗漏
- 国家详情增加来源可信度区块，显示本站核对时间、官方页面更新时间提示和来源说明
- 材料评估默认选择首个国家并随表单变化刷新结果，时间倒推器默认给出可用日期
- 管理页提前加载默认数据，保存前校验数据结构，并对 localStorage 读取、保存、清除失败给出提示
- 视觉层减少大面积装饰光斑，压低卡片圆角，让工具界面更轻、更利于扫描
- 首页和政策页加入 `viewport-fit=cover`，适配带安全区的移动浏览器
- 补充 `100dvh` 和安全区底部留白，减少移动端地址栏/底部手势区遮挡
- 优化锚点滚动偏移，点击快捷入口后标题不容易被顶部栏盖住
- 移动端快捷导航跟随安全区上移，表单和时间线工具更容易触达

## 本地运行

直接双击 `index.html` 可以打开。

更稳妥的方式是使用静态服务器，例如：

```bash
python -m http.server
```

或使用 VS Code Live Server。

## 数据维护

主要数据在 `data/visa-data.js`。

每条国家记录通常包含：

- 国家名、地区、国旗代码
- 是否需签证、签证类型、停留规则
- 办理时长、费用、有效期、面试要求
- 建议递交时间、官方申请路径
- 核心材料、补充材料
- 风险提示、社区高频问题
- 官方参考链接
- 可信度字段：`verifiedAt`、`sourceUpdatedAt`、`sourceNote`

新增或调整国家时：

1. 在 `data/visa-data.js` 中更新国家记录
2. 在 `assets/flags/` 补充对应的 `flagCode.svg`
3. 检查首页、政策页、材料评估、时间倒推器和 FAQ 是否正常渲染

如果需要临时本地覆盖数据：

1. 打开 `admin/index.html`
2. 粘贴新的 JSON 数组
3. 点击保存
4. 刷新前台页面即可生效

## 质量检查

建议提交前运行：

```bash
node --check app.js
node --check data/visa-data.js
git diff --check
```

同时建议确认：

- `data/visa-data.js` 必须先于 `app.js` 加载
- 政策页国家详情可以正常切换
- 手机端 360px 宽度下没有明显溢出，底部快捷导航不遮挡关键控件
- 时间倒推器能按国家生成差异化时间线
- 材料评估结果和 FAQ 能随国家切换正常变化

## 使用提示

- 本站内容用于行前信息参考，不替代官方规则
- 各国政策可能动态变化，递交前请以官方渠道最新公告为准
- 社区经验只适合做前期准备，不应覆盖官方要求
- 免签不等于无条件入境，边检仍可能要求说明行程、住宿、资金和离境安排
